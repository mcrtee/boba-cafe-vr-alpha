# VR Boba Cafe – Early Alpha

## Project Description

This project is an early alpha VR Boba Cafe created using Godot and OpenXR. The player can explore a cafe environment and interact with objects.

## Idea and Goal

The goal of this project is to create an immersive VR cafe where users can walk inside a boba shop and interact with drinks.

## Steps Completed

* Created VR project in Godot
* Added cafe environment
* Added player movement
* Added basic interaction
* Setup OpenXR
